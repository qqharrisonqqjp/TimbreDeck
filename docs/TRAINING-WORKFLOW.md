# GPT-SoVITS v2Pro 訓練與校對

在 **訓練素材** 有兩條路：

- **一鍵生成及訓練**：只匯入這裏明確選擇的錄音。去噪、按停頓切分、辨識台詞及跳過未辨識片段均可設定。選擇 **訓練設定** 可改模型名稱、輪數、批次。完成準備後，工作室會在 CUDA 裝置 0 微調 GPT 與 SoVITS，再分開提供資料集 ZIP 和微調模型 ZIP。
- **只建立資料集**：不啟動 GPU 訓練。辨識不到而沒有選跳過的片段會放進 `pending.list`，不會當成有效訓練資料。如果在一鍵訓練關閉辨識，或任何保留片段沒有台詞，工作室會保存可匯入的資料集及校對專案，等用戶填寫再訓練。

**手動訓練專案**可從一鍵資料集歷史一鍵匯入，也可匯入 TimbreDeck 資料集 ZIP 或直接加入錄音。匯入錄音可選語言、切分與 ASR 模型。同一來源以可摺疊的一組呈現；片段試聽用當前的起訖時間，不用先儲存。人手修改台詞不會被批量辨識蓋過。剔除只影響本專案，不會刪除原音。

聆聽並核對台詞後，把採用的片段標為「用於訓練」。開始按鈕和相鄰的進階設定固定在校對區的捲動位置。訓練會鎖定當時的專案版本，等現有工作完成；如有手動啟動的常駐模型，須先確認停用。

正式結果位於 **訓練結果**。資料集 ZIP 是校對後的 `dataset.list` 與相應 WAV；模型 ZIP 包含 GPT `.ckpt`、SoVITS `.pth` 及兩者校驗資訊。失敗時已封存的資料集仍可下載。請使用清晰、同一人聲且沒有重疊對白的素材；短樣本可以驗證流程，不代表微調品質。

**語音合成**和**模型管理**均可匯入本工作室匯出的模型 ZIP。每個角色可連結多套模型、選擇其一作預設，或使用 v2Pro 基礎模型。模型可改名，歷史保留當時所用的名稱。匯入時會驗證校驗值及權重格式，並以已安裝的 PyTorch 2.6 或更新版本重存為模型張量；本機 GPT-SoVITS 執行環境較舊時可用已連接的 CosyVoice 3 執行環境完成這一步。

**切分生成**在同一作業內只持有一個載入的模型。合併或打包 ZIP 完畢後會釋放臨時模型；手動常駐的型號維持啟動，除非用戶停止或確認切換。輸出歷史會分開顯示冷啟、模型生成和總時間；較舊沒有量測的紀錄仍可播放，並標為「未記錄」。
