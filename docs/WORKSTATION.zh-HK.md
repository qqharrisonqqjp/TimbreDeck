# 聲台啟動、工作區與復原

雙擊套件內的 **Open-TimbreDeck.cmd**；AI 用 **TimbreDeck-AI.exe ensure-running**。兩者使用同一啟動解析器及工作區鎖，會重用已執行的工作室。現有本機版本沿用以前的資料夾，新裝的可攜版預設用套件旁的 `StudioData`。可透過 `TD_STUDIO_DATA` 指定另一個絕對資料夾；可攜版腳本入口和 AI 都承認此設定。

在 **設定 → 關於 TimbreDeck** 或使用 `TimbreDeck-AI.exe status` 可查看相同版本和建置編號。預覽 ZIP 另附可自行匯入的 [2B 示範角色](examples/2B/profile.json) 和 [參考錄音](examples/2B/reference.wav)；其他角色及錄音、生成紀錄、引擎和模型另行保存。套件如需 AI 腳本，請提供可用的 Python 3.11/3.12 環境。收工後，只有沒有作業、沒有手動常駐模型、亦沒有客戶端使用的工作室才會閒置退出。

## 校對與辨識

要完全關閉服務，在左側「設定」下方按 **結束工作室**（細視窗先打開「工作區」）。確認後會儲存目前分頁的草稿並卸載常駐模型；仍有作業、檔案傳輸、儲存錯誤或草稿衝突時不會結束。其他分頁的改動請先儲存。關閉瀏覽器分頁本身不等同結束服務。

「訓練素材」內可切換快速訓練或手動校對。手動稿在輸入停頓後儲存，重新整理時會嘗試恢復同分頁尚未提交的草稿。兩個視窗同時修改時，先儲存的一方保持不變；另一方可另存副本或確認載入已儲存版本。瀏覽器禁用分頁儲存時，重新整理前請等「已儲存」。

批量辨識會依語言及上限分批，已完成的批次會先保存。如果某一批失敗，可用「重試辨識失敗片段」；取消不會抹掉已儲存的結果。人手核對的台詞不會被預設空白辨識覆寫。

## 作業與音訊

GPT-SoVITS 的「基礎版本」可以選 v2Pro、V5 Turbo 或 V5 Dev。V5 選項在 TimbreDeck 只用官方底模及參考錄音做合成，不顯示 v2Pro 微調介面，也不套用角色原有的 v2Pro 微調權重。兩個 V5 版本共用獨立 Windows/CUDA 引擎；在模型管理的「連接 GPT-SoVITS V5」填入該引擎資料夾，不會取代 v2Pro。模型權重可以已在引擎內，亦可從「官方模型」按版本管理。

GPU 作業仍一次一個。常駐模型需要明確確認才換；保留常駐時，清理錄音可改用 CPU。分段合成在所有片段完成前保持同一模型。UI／CLI 同樣可按作業 ID 查詢最近 128 筆非咪高峰分段的狀態；工作室重啟後，已產生的檔案仍可從輸出歷史重開。

「放到作業島試聽」可離開歷史頁繼續聽，並有停止按鈕。開咪前會暫停作業島播放；離開即時 STS 收音頁會先確認停止。細視窗用「工作區」按鈕展開導覽；減少動效設定和系統偏好都會關閉頁首裝飾視差。
