# TTS 常駐模型

在 TTS 工作區選擇引擎、模式（部分模式會選定模型版本）及 GPT-SoVITS 微調權重，再按 **開始啟動 TTS 模型**。預載期間佔用工作室的作業名額，但不產生錄音；等「常駐中」出現後，試讀及生成會重用目前模型。首句可能仍有 CPU 前處理、音色特徵或 CUDA 核心初始化。

同一時間 TTS 同 STS 只佔用一個常駐名額。按 **停止 TTS 模型** 會卸載；啟動另一個模型時，確認後先卸載舊模型。取消或切換驗證失敗不會關閉舊模型。載入新模型如果失敗，工作室會顯示錯誤，舊模型不會自動重開。生成進行中禁止切換／卸載；預覽、修改台詞、語速或音色參考不會自行重啟模型。

微調權重在同一路徑更換時，重新按啟動並確認；工作室會檢查權重大小及修改時間。已存在的常駐模型不會被來自本機 AI 的一般合成請求靜默替換。
